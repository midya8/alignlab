01 / Inspect a frozen state

The policy is fixed. The question can change.

Changing audit beta does not retrain the reward model or update the selected policy. Beta zero chooses the reference-conditioned reward maximizer among tied optima. Positive beta must be at least 0.000001.

Use a custom finite-policy JSON input

2 to 64 actions, rewards and supplied evaluation utilities within ±1,000,000. Probability sums must be within 1e-12 of one and are explicitly normalized. Zero reference support cannot receive policy mass. Utility is an optional evaluation axis, never an optimization input.

02 / Optimization is one question

How far from the best policy?

J(p) = E[p reward] - beta KL(p || reference). For positive beta, J* - J(p) = beta KL(p || p*). This identity concerns the supplied reward, not correctness, human preference satisfaction or generalization. Small negative gaps or residuals can be rounding error, not super-optimal policies.

03 / The KL budget is another question

How much reward can this movement buy?

33 sampled budgets, not an exhaustive plot of the continuum. The curve uses the supplied reward only; supplied utilities are listed separately. Unresolved and below-resolution samples are gaps, not optimality claims. Active-budget brackets and dual values are floating diagnostics, not outward-rounded certificates. Budgets below 1e-14 return the reference without claiming the optimum. Very near ties can return an unresolved bracket.

What this cannot tell you

A closed-form finite-policy optimum is tractable because every action is enumerated. It is not a scalable replacement for sequence-model optimization. Synthetic latent utility is available here only because the fixture defines it. Optimizing a noisy reward model can reduce that utility even when the optimizer gap is nearly zero.

Probability underflow, near ties, sum normalization and subtraction affect binary64 results. Supported log probabilities remain visible in the report even when a displayed probability underflows to zero. Nothing here certifies rounded-device arithmetic, causal attribution, safety or generalization.
